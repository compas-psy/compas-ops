## 5. Класс ошибок, который стоил сегодня целого дня

Один и тот же по форме, четыре раза подряд: **что-то настроено, но действует не там, где нужно.**

- Проверка схемы сверяла захардкоженный список колонок — новые не проверялись вовсе.
- Проверка авторизации дёргала адрес, не трогающий таблицу пользователей.
- Сборка в GitHub имеет переменные окружения, сборка образа на сервере — нет. Зелёная галочка сутки сосуществовала с падающей выкладкой.
- Корень сертификата установлен в систему, но Node системное хранилище не читает.

**Правило, выведенное из этого: проверять тем инструментом, который потом работает, а не тем, который под рукой.** Технический пульс из ТЗ панели — противоядие именно от этого класса.
