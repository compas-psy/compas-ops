#### D-260817-02 · Агентам разрешено писать код продуктов в ветке с pull request

- **Владелец:** CTO · **Критерий готовности:** первый pull request от агента с зелёными тестами.
- **Статус:** принято

- **Владелец:** CTO · **Срок:** правка устава — выполнено сегодня; техническая активация — по факту выдачи токена, целевой срок 19.08.2026 · **Критерий готовности:** устав §6.1 и `07_REPOS §2` содержат новый текст (выполнено); первый PR агента в `products/` проходит по новым правилам.
