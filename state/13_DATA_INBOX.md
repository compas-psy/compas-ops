# Входящие данные

Сюда учредитель кладёт метрические срезы; сюда же пишут коннекторы, когда их подключат.

**Как класть.** Готовые блоки для копирования — `03_SOURCES §2.1` (ежедневный снапшот, 2 минуты) и `03_SOURCES §2.2` (месячный, 20 минут перед бюджетным бордом). Новые блоки добавляются **сверху**, старые не редактируются. Неизвестное — прочерк `—`, настоящий ноль — `0`. Пустой блок с пометкой «нет данных» лучше отсутствия блока: агент должен отличать «не смотрели» от «ноль».

**Чего здесь не должно быть никогда.** Персональных данных пользователей, содержания клиентских записей, платёжных реквизитов, выгрузок с ФИО и контактами. Правила обезличивания — `03_SOURCES §3`.
