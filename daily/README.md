Деки ночного цикла: по одному на ночь, 4–6 слайдов.

    daily_ГГГГ-ММ-ДД.md      исходник, пишет агент по шаблону charter/04_TEMPLATES §6.1
    daily_ГГГГ-ММ-ДД.html    собирается из исходника
    daily_ГГГГ-ММ-ДД.pdf     то, что уходит учредителю

Собирается и отправляется одной командой:

    python3 tools/deliver.py --text outbox/ГГГГ-ММ-ДД_daily.txt \
                             --deck daily/daily_ГГГГ-ММ-ДД.md

Зачем дек, если есть сводка. Сводка отвечает на вопрос «что случилось» и
читается с экрана блокировки. Дек отвечает на вопрос «почему решили именно
так»: пятнадцать строк не вмещают доказательства, а решение без доказательства
через два дня невозможно проверить.

В git коммитится только исходник `.md` — собранные `.html` и `.pdf` в
`.gitignore` и пересобираются из него по требованию.

Ретенция: раз в квартал каталог чистится до последних 30 исходников. Деки
бордов хранятся целиком и живут в `board/` — заседание это протокол, а не
журнал.
