# HELM Panel

Production-фронтенд пульта. React + TypeScript + Vite, сборка в статику —
в проде node-процесса нет (ТЗ §10.5.2), файлы отдаёт Caddy.

```bash
npm install
npm run build          # tsc + vite → dist/
node tests/brief-compliance.mjs   # 27 проверок запретов брифа §2 и §5
node tests/screenshot.mjs         # визуальная приёмка §10.5.11, 3 вьюпорта
```

## Источники и их старшинство (§10.5.1)

```
HELM v3.3 security/architecture
  > HELM_PANEL_DESIGN_BRIEF.md      поведение и содержание
    > HELM Panel.dc.html            визуальная композиция
      > _ds/*                       референс палитры
```

Все три исходника лежат в `design-source/`, их SHA256 сверены с §6.1 и
записаны в `design-source/SOURCE_HASHES.txt`.

**Где реализация расходится с `_ds` и почему.** Bundled `_ds` — продуктовая
палитра СИМПАС: лес, золото, крем, `color-scheme: light`. Бриф §5 требует
нейтральную шкалу, один accent и тёмную/светлую по системной настройке.
По §10.5.1 бриф старше — поэтому в `styles/tokens.css` есть обе темы, а из
палитры взят только accent (forest-800: сдержанный и не Telegram-синий,
как требует бриф §8). Цветные фоны карточек, градиенты и тени не перенесены.

## Как запреты брифа держатся в коде

Запрет, который держится только на внимательности ревьюера, возвращается с
любой правкой. Поэтому:

| Запрет брифа | Чем удерживается |
|---|---|
| проценты без абсолюта | `MetricRow` требует `value: string`; автопроверка ловит форму `` `${x} %` `` |
| панель не зовёт модель | `panel.py` не импортирует ни модельного, ни сетевого клиента; тест по AST |
| нет круговых индикаторов, карточек в карточках | таких примитивов нет — нарушение видно на ревью |
| step-up на каждую запись | `api.decide()` требует `stepUpId` в сигнатуре |
| нет mock-данных | заглушка живёт в `tests/`, перехват на уровне сети, в бандл не попадает |
| анимации 150–200 ms | автопроверка длительностей |

## Приёмка

`tests/screenshots/` — снимки production-сборки в двух состояниях брифа §6
(«всё в порядке, 0 одобрений» и «критический алерт + 5 одобрений») на трёх

прокрутки, отсутствие ошибок в консоли и то, что «Сегодня» в спокойном
состоянии умещается на 390×844 без скролла.
