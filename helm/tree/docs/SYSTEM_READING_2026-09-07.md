# Три теста владельца 18:19–18:23 — один системный дефект

Распоряжение владельца 07.09.2026: «все мои тесты воспринимай
исключительно системно, а не как „найти решение для узкого запроса"».
Ниже — обязательное прочтение его прогонов: не три поломки, а одна.

## Узкие прочтения, которые здесь ЗАПРЕЩЕНЫ

* «ЭОТ не расшифровано» → словарь аббревиатур;
* «не понял „что такое"» → шаблон определения;
* «не понял „отдай файл"» → регулярное выражение на слово «файл».

Каждое из них починило бы ровно одну фразу владельца и оставило класс
дефекта на месте. Он это уже запрещал по поводу «беру» и «прилёт».

## Системное прочтение

Вопрос владельца несёт три вещи, и ни одна не доходит до исполнителя:

1. **ограничение источника.** «По книге Линде» — это условие поиска, а
   не вежливая приставка. Поиск его игнорирует и отвечает случайной
   главой той же книги. Ограничение по названному документу в системе
   ЕСТЬ (`test_dialogue_context_confines_the_search_to_the_named_
   document`), но работает только от контекста диалога, не от самого
   вопроса;
2. **тип требуемого ответа.** «Что такое X» требует определения, а
   получает любой фрагмент, где X упомянут. `QuerySpec.operation`
   сейчас знает `value`, `count`, `enumerate` — определения среди них
   нет, и отбор фрагмента типом ответа не управляется;
3. **форма выдачи.** «Отдай сам файл, а не текст» — это запрос
   оригинала. `documents.py` (§14.15) существует, но импортируется
   ТОЛЬКО из `api/panel.py`: в боте пути выдачи оригинала нет вовсе.
   Задача #25 закрыта для панели и не закрыта для бота.

Все три — один и тот же корень, названный владельцем в п.3
распоряжения: **QuerySpec не управляет исполнением**. Счёт («сколько»)
только что стал первым исключением; остальное по-прежнему сводится к
«покажи подходящий фрагмент».

## Что это значит для порядка работ

Правильная следующая работа — не три заплатки, а продолжение п.3:
довести контракт запроса до исполнителя целиком, начиная с
ограничения источника (оно даёт наибольший эффект на всех трёх
примерах сразу: правильная глава книги вместо случайной) и формы
выдачи (она не работает вовсе, а не работает плохо).
