# R7 — ответ только из доказанного

Распоряжение владельца 05.09.2026:

> R7 обязан поддерживать два пути. GRAPH — только по уже доказанным
> рёбрам. EVIDENCE_FALLBACK — каноническая личность с составом ≥1 →
> состав → упоминания → точный провенанс → доказательство. Личности без
> состава в ответах не участвуют никогда. Первая приёмка — «каких врачей
> я посещал?»: ФИО, специальность, дата/контекст если доказаны,
> источник. Если ФИО есть, а специальность не доказана — «ФИО —
> специальность не подтверждена». Никаких inference-догадок по названию
> клиники, отделению или контексту. Пустой GRAPH — не ошибка.

## Что сделано

`helm_core/knowledge/query_router.py` — исполнитель на два пути.

**GRAPH.** `EVENT --INVOLVES(role=doctor)--> PERSON` даёт человека и дату
события, `PERSON --HAS_ROLE--> CONCEPT` — специальность. Ничего не
выводится: берутся уже записанные рёбра.

**EVIDENCE_FALLBACK.** Личность → состав → упоминание с точным спаном →
диапазон символов в тексте источника. Личность без состава сюда не
попадает **по построению**: выборка начинается от строк состава, а не от
личностей. «Zero-member identities не участвуют в ответах» — свойство
запроса, а не проверка, которую можно забыть или обойти.

**Чем доказывается врачебность.** Правилом компилятора связей, взятым
целиком, а не пересказанным: маркер `врач[а-яё]*(-[а-яё]+)?` среди трёх
токенов непосредственно перед подписью. То же правило, что аттестовано в
R4, применённое к собственной цитате сущности вместо цитаты атома.
Пересказ разошёлся бы с оригиналом при первой правке одного из двух мест.

**Специальность** — только из дефисной связки («врач-уролог») и только
если слово после дефиса стоит в том же окне перед подписью. Иначе строка
ответа дословно: «ФИО — специальность не подтверждена».

**Дата** на пути доказательств не подтверждается никогда, и это
устройство, а не пробел: у узла-сущности даты нет, а дата документа —
не дата приёма. Подставить её значило бы догадаться.

**Название клиники, отделение и соседний текст доказательством не
являются.** «Иванов Пётр Сергеевич, отделение урологии» врача не
доказывает — отдельный тест.

## Замер, который делает «один» читаемым

Число «один врач» само по себе не говорит, один это из одного или один
из шестидесяти, и не говорит, не теряет ли строгое правило настоящих
врачей. Прогон 281 добавляет к тем же данным три счётчика
рассмотренного и два счётчика положения маркера. Правило доказательства
при этом не меняется: замеренные случаи в ответ не попадают.

```
considered  личности-люди с составом      6
            узлы в их составе            11
            упоминания с точным спаном   11
skipped     в цитате нет врачебного маркера  10
            маркер перед спаном в источнике   0
            маркер после подписи              0
```

Читается так. Личностей-людей с составом шесть, упоминаний с точным
провенансом одиннадцать. Врачебный маркер нашёлся у одного упоминания;
десять его не имеют — и **ни в одном из десяти** маркера нет ни левее
границы цитаты в самом документе, ни справа от подписи. То есть строгое
правило здесь не теряет ни одного врача: остальные пятеро — люди,
упомянутые в медицинских документах без ролевого маркера вообще
(пациент, родственники, подписи без слова «врач»).

Это и был вопрос, ради которого замер делался: «один» здесь означает
«один из шести человек, и пятеро не врачи по тексту», а не «один,
потому что правило слишком строгое».

## Что осталось владельцу решить

**Положение маркера.** Аттестованное в R4 правило смотрит только назад:
«врач-уролог Иванов И.И.» доказывает, «Иванов И.И., врач-уролог» — нет,
хотя вторая форма это обычная подпись под выпиской. На восьми пилотных
источниках разницы нет (замер выше: ноль), поэтому расширять правило
сейчас незачем — но на полном корпусе (R8) счётчик стоит смотреть
первым: если он перестанет быть нулём, решение о расширении принимает
владелец, а не R8 по ходу дела.

**Остаток R6.** Одна личность-человек с однословной подписью имеет один
узел в составе — строку, которую нынешние правила тождества не создали
бы (см. `R6_IDENTITY_2026-09-05.md`). Она участвует в ответах R7; после
пересборки трёх производных таблиц не участвовала бы. Пересборка
разрешена владельцем только при слиянии больше одного узла, а его нет.

## Итог

**R7 = DONE.** Живой E2E прошёл на реальных документах: вопрос владельца
дословно → канонические личности → упоминания → точный провенанс →
ответ, у каждого элемента которого есть доказательство. Пустой граф
отработан штатной веткой. Ни одного элемента без доказательства в ответ
не попало, и ни одной догадки в нём нет.

Ограничение названо прямо: на пилотных восьми источниках доказан один
врач. Это не оценка качества конвейера, а состояние корпуса — полный
ответ на этот вопрос даст R8.
