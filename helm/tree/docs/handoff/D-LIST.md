# D-LIST — указатель по D-кодам спеки

ТЗ использует короткие коды вида `D1`, `D2`, `D4`... для отдельных
micro-решений внутри более крупных разделов (§14.x и других). Они
разбросаны по коду и документам без единого места, где посмотреть все
разом — этот файл им и является. Не пересказывает решения — только
указывает, где искать полный текст.

**Важная оговорка**: этот список СОБРАН поиском по кодовой базе
31.08.2026 (`grep -rnoE "\bD[0-9]+\b"`), не переписан из исходной спеки
(`HELM_FINAL_v3.8`, недоступна в этом репозитории). Если у D-кода нет
записи ниже — либо он не встречается в текущей реализации вовсе, либо
использует другую форму записи, не найденную этим поиском. `D3`, `D7` и
далее — не найдены нигде в репозитории на момент составления.

## Как обновлять

Если находишь код `Dn`, которого нет в таблице — добавь строку с точной
цитатой источника, не описанием по памяти. Если код найден только в
одном месте без контекста, что он значит — так и запиши: «встречается
в X, точный смысл не установлен» — честнее, чем угадать.
