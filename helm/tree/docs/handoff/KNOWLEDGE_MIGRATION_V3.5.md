# KNOWLEDGE_MIGRATION_V3.5 — версии такой не существует в реальной истории

**Честная находка, не документ миграции**: версия `v3.5` не встречается
НИГДЕ в этом репозитории, кроме одного места — самого требования §35
(`ROADMAP-TO-DONE.md`, список из 23 документов передачи), которое
называет этот файл по имени.

## Что реально существует

Дельты версий HELM Knowledge в этом репозитории идут:

```
v3.4 (V3.4-DELTA.md) → v3.7 (V3.7-DELTA.md) → v3.8 (V3.8-DELTA.md)
```

`v3.5` и `v3.6` нигде не упоминаются — ни как версия ТЗ, ни как этап
разработки, ни как номер миграции Alembic. Прыжок с v3.4 сразу на v3.7
— не опечатка в этом документе, а факт всей истории репозитория,
проверенный поиском по всей кодовой базе.

## Возможные объяснения (не проверено, честно помечено как догадка)

- Исходная спека (`HELM_FINAL_v3.8`, недоступна в этом репозитории)
  могла иметь промежуточные ревизии v3.5/v3.6, которые были объединены
  или переименованы к моменту, когда реализация дошла до v3.7 — этот
  репозиторий фиксирует только то, что реально стало кодом.
- Список документов §35 мог быть составлен по шаблону/более раннему
  плану, ссылающемуся на версию, которая впоследствии не материализо-
  валась под этим номером.

## Что делать следующему, кто наткнётся на это требование

Не изобретать миграцию для версии, которой не было. Если появится
доступ к исходному ТЗ (`HELM_FINAL_v3.8`) — сверить, действительно ли
там описана отдельная фаза v3.5, и либо переименовать этот документ под
её реальное содержание, либо зафиксировать явно, что требование §35
устарело и версии v3.5 в финальной истории проекта не было вовсе.
