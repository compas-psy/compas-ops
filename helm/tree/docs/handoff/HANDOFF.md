# HANDOFF — точка входа для нового инженера/агента на HELM

§35 требует этот документ как отправную точку. Он не пересказывает
остальные — только говорит, что где искать и в каком порядке читать.

## Прочитать в первую очередь (в этом порядке)

1. `ARCHITECTURE.md` — что за система, из чего состоит, кто чем владеет.
2. `OPERATIONS.md` — как деплоить, проверять состояние, читать `verify`.
3. `SECRETS_MAP.md` — где какой секрет живёт (без значений).
4. `TROUBLESHOOTING.md` — реальные классы багов, которые уже случились —
   прочитать ДО того, как наступить на те же грабли.

## Где живёт правда о статусе

- **`implementation-state/STATUS.json`** — единственный источник
  "что сделано, что открыто, что найдено живьём". `open_findings`
  (реальные баги с ID `F-YYMMDD-NN`), `resolved_this_cycle` (что
  закрыто), `task` (текущий нарратив).
- **`implementation-state/ROADMAP-TO-DONE.md`** — полный план до конца
  проекта, блоками. Читать "Где мы сейчас" в начале файла для быстрой
  ориентации (сверять с датой — этот файл обновляется по ходу работы, не
  всегда синхронно с STATUS.json).
- **`docs/adr/README.md`** — какие архитектурные решения приняты,
  какие явно нет (не путать «не написан ADR» с «не принято решение» —
  таблица различает оба честно).

## Правило, которое действует для всего проекта

**«Готово» значит проверено на живом сервере.** Код, прошедший тесты,
но ни разу не выкаченный — это «готово в коде», отдельная категория.
Каждый прошлый выкат находил 2-4 живых бага, невидимых в песочнице
(права на каталоги, ABI библиотек, сертификаты Минцифры, сетевые
блокировки) — см. `TROUBLESHOOTING.md`.

## Что технически не завершено прямо сейчас (не полный список — детали в ROADMAP-TO-DONE.md)

- Функциональная проверка живьём ZIP-пачки/«Запомни»/выдачи файла
  через реального пользователя (не только Python-уровень) — отдельная,
  ещё не пройденная задача.
- Graphify (`E13 = INSUFFICIENT_REAL_CORPUS`) — слой 1
  `knowledge_relations` готов, сам эксперимент ждёт реального
  Obsidian-вклада владельца.
- Milestone C (домены) и D (SignalAI) — не начаты, оба намеренно.
- Полный список §35 (этот документ + 18 файлов рядом) — восполняется
  по мере необходимости, не факт, что покрывает вообще всё, что
  спрашивает исходная спека (которой нет в этом репозитории).

## Если что-то в этих документах разошлось с реальностью

Обновлять документ передачи в том же коммите, где меняется код/решение,
которое он описывает — не раньше и не позже (тот же принцип, что уже
действует для `docs/KNOWLEDGE_MODELS.md`). Найденное расхождение —
находка (`STATUS.json::open_findings`), не молчаливая правка задним
числом.
